# Panduan Bahasa Melayu

1. Clone atau muat turun repository ini.
2. Untuk Codex, salin folder skill pilihan ke `.agents/skills/` dalam projek.
3. Untuk VS Code Copilot, salin ke `.github/skills/` dalam projek dan semak sama ada skill dikesan.
4. Untuk ChatGPT, fail GitHub tidak dipasang secara automatik. Berikan SKILL.md sebagai konteks atau gunakan integrasi skills yang disokong.
5. Jalankan `python3 scripts/validate_skills.py`.

**Penting:** Ujian struktur tidak menjamin keserasian runtime. Semak setiap platform secara berasingan.
