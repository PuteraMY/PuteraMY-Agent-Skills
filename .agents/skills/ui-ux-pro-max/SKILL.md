Upstream project: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

## When to apply

Use alongside `frontend-design` and `design-system` when designing, implementing, auditing, or polishing any user-facing screen, component, navigation, forms, tables, data visualizations, animation, or responsive behavior.

## Design workflow

1. Inspect the existing product, its users, code, constraints, and working flows. Preserve existing features.
2. Establish product-specific visual direction; define semantic color, typography, spacing, radius, shadow, and motion tokens before implementing new components.
3. Prioritize accessibility and task success: contrast, semantic HTML, keyboard access, visible focus, descriptive labels, touch targets, and useful feedback.
4. Make layouts mobile-first, test common widths and reduced-motion preference; prevent overflow, overlap, and content clipping.
5. Use restrained, meaningful motion with consistent timing; avoid decorative animations that harm performance or usability.
6. Design loading, empty, error, success, and disabled states, including validation and recovery.
7. Verify actual rendered behavior, keyboard navigation, mobile and desktop responsiveness, performance, and regression tests. Report what was tested and what remains unverified.
8. For premium polish, choose distinctive but coherent type hierarchy, whitespace, iconography, surfaces, and micro-interactions that suit the product rather than generic templates.
