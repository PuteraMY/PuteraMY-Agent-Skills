## When and how to use
When coding against changing frameworks or APIs, use Context7 where available to retrieve current, version-appropriate official documentation and examples. Confirm package version from lockfile first, prefer official sources, check breaking changes and validate sample code in the actual project. Context7 MCP/service must be connected separately; this guide alone does not enable live documentation retrieval.
