# Verification Before Completion
Upstream inspiration: https://github.com/obra/superpowers
This is a PuteraMY adaptation.

Before saying done: inspect diff, run the actual available test/build/lint commands, check deployment state and HTTP/browser behavior, validate key acceptance criteria, and document unresolved issues. Distinguish code written, tests added, tests executed, preview deployed and production released. Never invent test results. Keep production unchanged without approval.
