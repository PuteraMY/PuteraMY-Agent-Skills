# Motion Animation — PuteraMY guide
Official docs: https://motion.dev/docs
Official agent skill installer (optional, not installed here): https://motion.dev/docs/react
This file is a locally authored workflow guide, not the full Motion AI Kit.

Use Motion for complex interactive animation in React or vanilla JS when justified; use CSS transitions for simple hover/focus effects. Inspect framework, dependencies, bundle constraints and user journeys before selecting a library. Define motion tokens (duration/easing/spring), entrance/exit, modal, menu, drag and state transitions. Prioritize transform and opacity, cleanup on unmount, and respect prefers-reduced-motion. Never animate essential content invisibly. Test touch, keyboard, low-end mobile, layout shift and performance. Don't add a package until the target project needs it.
