# Web Design Guidelines
Upstream: https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines
This is a PuteraMY workflow adaptation, not a verified copy of the complete upstream skill.

When reviewing UI, inspect actual source and rendered pages. Audit semantic HTML, labels, focus visibility, keyboard navigation, contrast, touch target sizes, form feedback, loading and error states, image alternatives, mobile overflow, reduced motion, typography and localization. Report concrete file:line findings by severity, fix without changing working behavior, then verify in a real browser. Do not assert full compliance without testing.
