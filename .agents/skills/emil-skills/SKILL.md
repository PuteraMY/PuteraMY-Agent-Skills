## When to use
Use for web interaction design and animation polish. Favor purposeful timing, spring dynamics, coordinated transitions, refined microinteractions, stable layouts and reduced-motion support. Prototype transitions in browser; inspect actual 60fps behavior and frame timing. Avoid motion for motion's sake. Select specific upstream subskills only after inspecting the repository.
